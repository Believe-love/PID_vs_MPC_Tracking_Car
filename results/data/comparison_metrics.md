# PID 与 MPC 仿真对比

数据来自 `results/data/pid_timeseries.csv` 和 `results/data/mpc_timeseries.csv`。直道5已加长到 2.90 m。没有改控制律。

## 仿真条件

- 随机种子：42
- 控制周期：0.020 s
- 参考路径长度：9.424 m
- 初始横向偏差：0.008 m，初始航向偏差：0.0 rad
- 两边 t = 0 的位姿相同。PID 跑了 1305 步，MPC 跑了 1605 步。
- MPC 参数保持项目原值：N = 10，Q = [5000.0, 80.0]，R = 0.1，S = 1.0，P = [10000.0, 200.0]。
- `freeze_linearization = True`：预测时域内参考角速度保持当前拍的 ω_r，不读取前方路段曲率。

## 量定义

- `e_y` 是车轴中心到路径的几何横向误差，路径左侧为正，单位 m。传感器加权误差在八路都看不到线时会被置 0，并且在约 ±0.06 m 饱和，所以不用它做偏离对比。
- `omega_cmd` 是轮速滞后之前的角速度指令。MPC 用控制器输出；PID 由左右轮 PWM 按同一差速模型反算。
- `omega_r = kappa_r * v_r`。急弯和直角弯 `v_r = 0.18 m/s`，其余 `0.30 m/s`。
- 直道/缓弯只统计直角弯前视窗之前、段类型为 straight 或 gentle 的样本，避免丢线后投影落到最后一段直道上。
- 急弯按段类型 sharp。直角弯指标从弧长进入 `s0 - 0.075 m` 起，到连续 0.2 s 回到下一段直道（到线距离 < 0.05 m 且 |e_y| < 0.03 m）为止；回不去就计到仿真结束。
- 图上的色带比指标窗口短：急弯是投影落在 sharp 段；直角弯是弧长落在 `[s0 - 0.075, s1 + 0.12] m` 且到线距离 ≤ 0.18 m。色带取两车时间段的并集。
- 几何丢线：|e_y| > 0.06 m（传感器阵列半宽）连续不少于 3 步。传感器丢线沿用原仿真：Σweight = 0 连续不少于 3 步。
- 控制量变化率是相邻拍 `omega_cmd` 之差除以 dt 后的 RMS。直角弯的曲率阶跃会抬高弯道内的这个数；直道/缓弯上的变化率用来看持续抖动。
- 入口提前量：在 ω_r 阶跃之前 0.55 s 内，同方向 ω_cmd 第一次超过 0.5 rad/s 的时刻。直道起伏大约 ±0.2 rad/s，0.5 rad/s 用来避开这些起伏。若阶跃前一拍仍不低于这个幅度，记为“保持”；否则记为“已回落”。和阶跃同一拍才抬起来的，不算提前。

## 数值对照

- 直道/缓弯 RMS 横向误差：PID 0.0022 m，MPC 0.0030 m。PID 更低，绝对差 0.8 mm，MPC 比 PID 高 36.0%。
- S 弯 RMS 横向误差：PID 0.0034 m，MPC 0.0027 m。MPC 更低，绝对差 0.7 mm，相对 PID 减小 20.7%。
- 急弯最大横向误差：PID 0.0086 m，MPC 0.0055 m。MPC 更低，绝对差 3.1 mm，相对 PID 减小 36.2%。
- 急弯 RMS 横向误差：PID 0.0053 m，MPC 0.0027 m。MPC 更低，绝对差 2.6 mm，相对 PID 减小 49.2%。
- 急弯平均速度：PID 0.297 m/s，MPC 0.193 m/s。MPC 更低，绝对差 0.105 m/s，相对 PID 减小 35.2%。
- 直角弯最大横向误差：PID 0.8893 m，MPC 0.0942 m。MPC 更低，绝对差 0.7950 m，相对 PID 减小 89.4%。
- 直角弯 RMS 横向误差：PID 0.4888 m，MPC 0.0553 m。MPC 更低，绝对差 0.4334 m，相对 PID 减小 88.7%。
- 全程控制量变化率 RMS：PID 43.66 rad/s²，MPC 7.74 rad/s²。MPC 更低，绝对差 35.92 rad/s²，相对 PID 减小 82.3%。
- 直道/缓弯控制量变化率 RMS：PID 4.74 rad/s²，MPC 4.74 rad/s²。绝对差 0.00 rad/s²，相对差不到 5%。
- 急弯控制量变化率 RMS：PID 4.86 rad/s²，MPC 5.94 rad/s²。PID 更低，绝对差 1.08 rad/s²，MPC 比 PID 高 22.2%。
- 直角弯路径窗口控制量变化率 RMS：PID 71.53 rad/s²，MPC 31.03 rad/s²。MPC 更低，绝对差 40.51 rad/s²，相对 PID 减小 56.6%。
- 急弯+直角弯控制量变化率 RMS：PID 91.96 rad/s²，MPC 14.87 rad/s²。MPC 更低，绝对差 77.09 rad/s²，相对 PID 减小 83.8%。

- 路径完成：PID 因离线过远提前结束，MPC 跑完设定路径。

## 预瞄

图 `compare_preview.png` 画的是 MPC 的 ω_cmd 和当前投影点的 ω_r。点线是轴心进入弯道、ω_r 发生阶跃的时刻。
这版 MPC 的 `freeze_linearization` 为 true，预测时域里的参考角速度保持当前值，不读取前方路段的曲率。弯道内指令高于 ω_r，是在修已经出现的误差，不是提前打角。

- MPC 急弯入口：阶跃前 0.55 s 内，同方向指令没有超过 0.5 rad/s。指令是和 ω_r 一起抬起来的。进入前车速对应的传感器前视时间约 251 ms。
- MPC 直角弯入口：提前 200 ms 抬起，阶跃前已回落。阶跃前同方向峰值 1.07 rad/s。进入前车速对应的传感器前视时间约 251 ms。抬起没有保持到阶跃前一拍，不能算完成的预打角。
- PID 急弯入口（同一套阈值，供对照）：提前 120 ms，并保持到阶跃前。阶跃前同方向峰值 0.96 rad/s。进入前车速对应的传感器前视时间约 252 ms。
- PID 直角弯入口（同一套阈值，供对照）：提前 260 ms，并保持到阶跃前。阶跃前同方向峰值 3.94 rad/s。进入前车速对应的传感器前视时间约 260 ms。提前量和车头传感器看到弯道的时间同量级。

## 图上能核对的结论

轨迹图在急弯之前，红线和蓝线都贴着灰色参考线。直角弯之后红线离开参考线并且没有回来，蓝线向外鼓出一截后又回到线上。右图把这段放大，离开路径的是 PID。
误差图在橙色急弯里两条线都还在 ±1 cm 以内。MPC 急弯最大横向误差 5.5 mm，PID 为 8.6 mm。粉色直角弯之后，PID 一直降到 88.9 cm 并且仿真结束；MPC 降到 9.4 cm 后拉回来。两条线都会穿过 ±6 cm 的丢线线，差别是 PID 回不来。
指令图在直道、缓弯和急弯上，红线和蓝线的起伏幅度接近：直道/缓弯变化率都是约 4.74 rad/s²，急弯段 PID 4.86、MPC 5.94 rad/s²。剧烈来回打方向盘出现在直角弯之后的红线上；蓝线是打到上限、停住，再收回。
预瞄图的急弯入口，蓝线是和灰色虚线一起抬起来的，阶跃前没有超过 0.5 rad/s。直角弯入口在点线之前有一个大约 1 rad/s 的鼓包，但点线之前已经回到负值；随后和 ω_r 一起打到约 4.78 rad/s 的上限。ω_r 本身阶跃到 7.2 rad/s，超出纵轴，也超出这个上限。
直角弯半径 0.025 m、低速参考 0.18 m/s 时，几何上需要角速度 7.20 rad/s，而左右轮 PWM 上限对应的角速度只有 4.78 rad/s。这条直角弯比当前车速允许的转弯更急，所以两边都会在这里偏离；MPC 偏离后能拉回，PID 不能。
急弯上 MPC 平均速度 0.19 m/s，PID 为 0.30 m/s。急弯误差更小，有一部分来自 MPC 按路段把参考速度降到 0.18 m/s，不全是反馈律的差别。
